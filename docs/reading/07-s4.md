# S4: structured state spaces

**Citation verified 2026-10-27:** Albert Gu, Karan Goel, Christopher Ré,
*Efficiently Modeling Long Sequences with Structured State Spaces*, ICLR 2022.
The preprint first appeared in 2021; this note uses
[arXiv v3, 5 August 2022](https://arxiv.org/abs/2111.00396v3).
The [conference paper](https://openreview.net/attachment?id=uYLFoz1vlAC&name=pdf)
confirms the venue. No experiments were reproduced for this note.

## Method

S4 discretizes a continuous linear state-space system. Its structured state
matrix permits efficient computation of a convolution kernel, while retaining
an equivalent recurrent evaluation. The construction uses a normal matrix plus
a low-rank correction, transformed into a diagonal-plus-low-rank representation;
Cauchy-kernel calculations avoid naive repeated dense matrix operations.
[Paper, Sections 2–3](https://arxiv.org/pdf/2111.00396v3).

## Claims and actual baselines

The authors report improved long-context learning and efficient sequence
processing. Efficiency comparisons include LSSL, standard attention, Performer,
and Linear Transformer. Long Range Arena comparisons include several attention
variants; additional studies cover speech, images, language, and forecasting.
These are different experiments, not one universally matched comparison.
The revised paper explicitly identifies updated benchmark results in Appendix
D.5; original and revised scores should not be mixed.
[Sections 4.1–4.3, Tables 2–9, Appendix D.5](https://arxiv.org/pdf/2111.00396v3).

## What could be missing? — our assessment

Our proposed surface contains only 120 coordinates. A method motivated by long
contexts may add overhead without helping this relatively short regression task.
Sequence length alone does not measure its usefulness: the relevant question is
whether the ordering creates dependencies that improve validation error under
our common budget. Strong results on a classification benchmark cannot answer it.

Financial surfaces are indexed by two continuous coordinates, not a physical
one-dimensional time axis. Flattening maturities and strikes introduces artificial
neighbors. We must examine whether errors cluster at maturity boundaries, whether
output depends on unrelated query points, and whether changing query density
changes the learned function. Merely accepting a variable sequence length does
not establish coordinate or resolution generalization.

## Consequences for this project — our decisions

Keep S4 as methodological context for M3. The selected implementation direction
is the bidirectional selective SSM described in [the Mamba note](08-mamba.md),
not an undocumented approximation labeled as original S4. Full S4 would require
additional care with complex arithmetic, stable parameterization, discretization,
and kernel construction. That is a plausible alternative, but unnecessary for
the first architecture comparison under the stated scope.

At T3.3, specify the canonical coordinate order and how predictions are restored
to the requested order. Count both directional passes when reporting compute;
match trainable parameters and tuning opportunity against M0. At Gate 4, measure
actual latency on the project grid and devices. Do not transfer published
long-sequence speed ratios into this project's results. These are planned checks,
not completed validation or changes to the evaluation protocol.
